# Code fourni

Ce repertoire est une bibliotheque d'adaptation fournie avec le projet. Il
recupere le flux HTTP et interprete son JSON avec libcurl et cJSON.

Il ne fait pas partie du travail des etudiants et ne doit pas etre modifie. Le
contrat utile au projet est limite a `include/projet/sensor_source.h`.

Les fichiers de `cjson/` proviennent de cJSON 1.7.19 et sont distribues sous
licence MIT; consulter `cjson/LICENSE`.
