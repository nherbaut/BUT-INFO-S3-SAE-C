# Évaluation de la SAE C

L'évaluation associe le projet réalisé en équipe et une mise en situation
individuelle sur votre propre code.

## Projet en équipe — 20 %

Réalisez le projet capteurs en binôme dans un **fork privé** du projet.

- Ajoutez l'enseignant comme **mainteneur** du projet.
- Nommez obligatoirement le projet :
  `2026-2026-SAE-C-Projet-NOM1-NOM2`.
- Remplacez `NOM1` et `NOM2` par les noms des deux membres du binôme.
- Conservez un historique de commits qui permet de suivre votre progression.

Les 20 % de cette partie évaluent le projet initial : son fonctionnement, le
respect du sujet et la qualité du dépôt rendu.

## DS individuel — 80 %

Pendant le DS, les enseignants vous communiqueront une nouvelle fonctionnalité
à implémenter à partir de votre projet. Vous disposerez de **45 minutes** pour
la réaliser individuellement dans une branche nommée `ds`.

Le projet utilisé pour le DS doit être votre **fork privé réalisé en binôme**.
L'enseignant doit y avoir été invité avec le rôle de **mainteneur**. Créez la
branche `ds` dans ce fork avant de commencer l'épreuve.

Vous devrez donc être capable de lire votre code, d'en expliquer les choix et
de le modifier de façon autonome. La fonctionnalité donnée au DS sera conçue
pour s'intégrer au projet existant : elle pourra nécessiter de modifier une
structure, une fonction, un test, le traitement des erreurs ou une sortie.

La fonctionnalité du DS est évaluée sur votre projet tel qu'il a été rendu.
Les fonctionnalités préexistantes nécessaires à la nouvelle fonctionnalité
font partie de l'évaluation.

L'utilisation d'une IA générative pendant la réalisation du projet est donc
contre-productive par rapport à cette évaluation individuelle. Vous devez être
en mesure de coder sans aide externe, avec les outils adaptés, et de comprendre
chaque partie du dépôt que vous rendez.

### Ressources autorisées pendant le DS

Vous pouvez utiliser :

- le PDF du cours ;
- VS Code comme environnement de développement ;
- les pages de manuel, notamment avec `man`.

L'utilisation d'une IA générative est **interdite** pendant le DS. Tout usage
d'une IA générative entraîne la note de **zéro** pour la partie DS de
l'étudiant concerné.

## Répartition de la note

| Partie évaluée | Poids |
| --- | ---: |
| Projet initial en équipe | 20 % |
| Fonctionnalité réalisée individuellement pendant le DS | 80 % |
